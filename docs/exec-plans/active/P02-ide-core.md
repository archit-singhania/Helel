# P02 — IDE core

## Goal

Turn the desktop shell into a safe local code editor.

## Planned slices

1. Monaco editor integration and language modes
2. Read-only project tree and file opening through typed Rust commands
3. Tab management and dirty-state model
4. Save and save-all
5. Create, delete, and rename with workspace boundaries
6. Keyboard shortcuts
7. Search and replace
8. Diff editor
9. Diagnostics and problems panel
10. IDE core integration tests

Terminal execution, Git operations, autonomous agent behavior, and repository indexing remain outside this phase.
