# P04 — Code intelligence

## Goal

Build local project understanding for deterministic navigation and later agent context retrieval.

## Planned slices

1. Project and framework detection
2. Incremental source parsing
3. File, symbol, and reference index
4. Persistent local index storage
5. Definition, reference, and symbol navigation
6. Ranked context retrieval with explicit limits
7. Performance, correctness, and workspace-boundary tests

Agent planning and model inference remain outside this phase.
