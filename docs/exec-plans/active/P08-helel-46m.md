# P08 — Helel-46M product model

## Goal

Scale the validated architecture to the first product model and measure useful local coding behavior.

## Planned slices

1. Helel-46M architecture and memory profiles
2. Production tokenizer vocabulary and context configuration
3. Licensed corpus mixture and sampling policy
4. Pretraining and fill-in-the-middle curriculum
5. Held-out completion, repair, and repository-context evaluations
6. Quantized checkpoint experiments and quality comparison
7. Reproducible training report and release-candidate checkpoint contract

Desktop inference and agent integration remain outside this phase.
