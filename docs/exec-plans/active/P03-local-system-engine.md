# P03 — Local system engine

## Goal

Add auditable local process, terminal, Git, patch, and permission services.

## Planned slices

1. Process lifecycle and output streaming
2. Terminal session model
3. Git status, diff, branch, and safe operations
4. Structured patch application and rollback
5. Command risk classification and approval records
6. Workspace watcher and external-change handling
7. Integration tests across filesystem, process, Git, and security boundaries

Repository indexing, autonomous planning, and model integration remain outside this phase.
