# P06 — Dataset and tokenizer pipeline

## Goal

Create a reproducible, legally traceable local pipeline for training data and the Helel tokenizer.

## Planned slices

1. Source registry, license metadata, and allowlist policy
2. Local ingestion, normalization, filtering, and secret removal
3. Exact and near-duplicate detection
4. Train, validation, and test split isolation
5. Deterministic tokenizer training and evaluation
6. Dataset manifests, checksums, lineage, and quality reports
7. Small fixture pipeline for continuous verification

Large corpus acquisition and model training remain outside this phase.
