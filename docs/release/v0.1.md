# Helel v0.1 developer preview

Run `CARGO_NET_OFFLINE=true python3 scripts/verify.py` before packaging. The gate validates code, contracts, offline policies, performance budgets, frontend assets, and the native debug application.

The desktop works without model weights through deterministic agent sessions. A learned runtime requires a compatible tokenizer, model configuration, and evaluated safetensors checkpoint. Do not label a checkpoint as Helel-46M release candidate unless `release_candidate_manifest` accepts all four evaluation categories.

Public distribution additionally requires macOS signing and notarization, clean-machine installation tests, accessibility review, dependency/security review, and an approved product-model data and evaluation report.
